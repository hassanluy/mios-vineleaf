# ورق عنب ميوس

موقع ورق عنب ميوس (الأعظمية، بغداد): منيو بالأسعار، ستوري للبوكسات، سلة طلب ترسل رسالة جاهزة على واتساب، وحجز للمناسبات.

الرابط: https://hassanluy.github.io/mios-vineleaf/

## تعديل المحتوى

كل المحتوى بملف `index.html`، داخل السكربت بآخر الملف:

- `PRODUCTS`: الأصناف والأسعار (بالألف دينار) والصور
- `GROUPS`: أقسام المنيو
- `STORIES`: دوائر الستوري وصورها
- `TPL`: قوالب رسائل الواتساب
- `WA` و `PHONE`: رقم الواتساب

الصور بمجلد `img/` بصيغة WebP.

## النشر

GitHub Pages من فرع `main` والمجلد الجذر (`/`). أي تعديل يوصل لفرع `main` ينشر تلقائياً خلال دقيقة أو دقيقتين.
